# Sala Cero v22

Reinicio de interfaz centrado en jugar.

- Sin login, cuentas, perfiles, niveles, XP, logros ni carrera.
- Responsive automático: no existe selector PC/móvil.
- Mobile-first con safe areas de iPhone, controles táctiles grandes y modales tipo bottom-sheet.
- Motores de juego conservados y limpiados de dependencias de gamificación.
- PWA/offline simplificada y paquete más ligero.
