# Instalación de Tute IA

## Actualizar GitHub Pages

1. Descomprime el ZIP de la versión 14.
2. Sube todo su contenido a la raíz del repositorio.
3. Sustituye los archivos anteriores, incluida la carpeta `assets`.
4. Espera a que GitHub Pages complete el despliegue.
5. Abre la web y realiza una recarga forzada con `Ctrl + Shift + R`.

## Instalar en Android

1. Abre la web con Chrome, Edge o un navegador compatible.
2. Pulsa `APP` o entra en `Instalar y gestionar` desde el menú principal.
3. Selecciona `Instalar Tute IA`.
4. El icono aparecerá en la pantalla de inicio y la aplicación se abrirá en modo independiente.

## Instalar en iPhone o iPad

1. Abre la web con Safari.
2. Pulsa el botón Compartir.
3. Selecciona `Añadir a pantalla de inicio`.
4. Confirma el nombre y pulsa `Añadir`.

## Prepararla para jugar sin conexión

1. Abre la aplicación una vez con conexión.
2. Espera a que el panel indique que el juego offline está listo.
3. Cierra y vuelve a abrir la aplicación.
4. Para comprobarlo, activa temporalmente el modo avión y abre Tute IA.

La música ligera se guarda automáticamente. La pista de treinta minutos se descarga únicamente al pulsar `Descargar música completa`.
