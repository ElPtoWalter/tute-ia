Mentiroso

Cinco dados ocultos por jugador. Sube la apuesta o acusa de mentira. Nadie conoce todos los dados hasta que alguien se atreve a desafiar.

2–8 personasDadosFaroleoPasa el móvil
🎲

Cómo se juega

  1. Cada jugador empieza con cinco dados virtuales.
  2. En tu turno haces una apuesta: cantidad de dados + cara. Debe superar la apuesta anterior.
  3. El siguiente jugador puede subir o pulsar Mentira.
  4. Al desafiar se muestran todos los dados. Quien falle el desafío pierde un dado; gana quien conserve dados al final.
